### Focus

**Native & systems** — C and C++ on Windows and Android. Small binaries, explicit memory management, and hand-written ARM or x86 when the compiler won't cooperate.

**Reverse engineering & instrumentation** — PLT/GOT and import resolution, structure and vtable recovery, function hooking and inline patching with Frida and Dobby.

**Rendering & interface** — Direct2D, DirectX 11, Dear ImGui and WinUI 3. Custom widgets, animation and layout written by hand rather than pulled from a component library.

**Android & tooling** — NDK modules for arm64-v8a and armeabi-v7a, ADB-driven device workflows and Lua configuration layers.
